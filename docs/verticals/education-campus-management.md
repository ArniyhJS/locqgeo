# Education & Campus Management

### Problem

Schools and exam bodies need reliable attendance, exam-center verification, and campus access control. Fake attendance and impersonation are persistent issues.

**Additional challenges:**

- Proxy attendance is common in large lecture halls and exam centers.
- Administrators waste time reconciling manual attendance registers.
- Parents and sponsors want proof of class participation.
- Campus access badges can be shared or lost.
- Accreditation bodies require auditable attendance records.

### How LocqGeo helps

- Classrooms, exam halls, and campus gates become geofences.
- Students scan for attendance; the engine confirms they are physically present.
- Integration with ID systems reduces impersonation risk.

### Key features used

- ATTENDANCE action, scheduled campaigns, device binding, duplicate checks.

### Revenue model

- Per-student annual license.
- Institutional SaaS.

### Example

A university records lecture attendance via LocqVerify. Students earn credit only after verified attendance, and administration sees real-time engagement metrics.

**Additional examples:**

- A university records lab attendance by having students scan at each laboratory entrance.
- An exam body verifies candidates are physically inside the exam hall before releasing question papers digitally.
- A coding bootcamp only issues completion certificates after verified attendance across all modules.
- A school uses verified presence to automate parent notifications when a child arrives on campus.
