# Security & Patrol Services

### Problem
Security firms need proof that guards patrolled designated checkpoints at correct intervals.

**Additional challenges:**
- Clients cannot verify that guards patrolled every required checkpoint.
- Manual patrol logs are filled out retrospectively and can be forged.
- Incident response is delayed when supervisors do not know guard locations in real time.
- Security contracts often bill for patrols that were skipped.
- Large campuses and industrial sites are hard to cover consistently.

### How SpottGeo helps
- Patrol checkpoints become geofences.
- Guards scan NFC/QR tags in sequence.
- Supervisors receive real-time patrol confirmation and missed-point alerts.

### Key features used
- Ordered checkpoint campaigns, timestamp verification, missed-checkpoint alerts.

### Revenue model
- Per-guard monthly license.
- Security operations SaaS.

### Example
A mall’s security team uses SpottVerify to confirm guards checked every floor and parking level every hour.

**Additional examples:**
- A mall security team confirms hourly patrols through geofenced checkpoint scans.
- An industrial plant verifies that fire-safety rounds covered all mandatory zones overnight.
- A residential estate tracks guard presence at gates and perimeter points.
- A concert venue uses ordered checkpoints to ensure crowd-control staff cover the entire perimeter.
