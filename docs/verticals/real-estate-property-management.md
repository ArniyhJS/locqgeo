# Real Estate & Property Management

### Problem
Property platforms need to confirm agents conducted showings, inspections, or handovers. Fake viewing reports waste landlord and buyer time.

**Additional challenges:**
- Landlords receive complaints that agents did not show the property.
- Fake viewing reports waste time and damage trust.
- Tenants and agents dispute move-in/move-out inspection timing.
- Property platforms lack data on which listings generate real foot traffic.
- Multiple agents showing the same property create coordination conflicts.

### How SpottGeo helps
- Properties become geofences.
- Agents scan at the location; prospective tenants can also verify they attended.
- Landlords get tamper-proof showing reports.

### Key features used
- AUDIT action, timestamp verification, agent/customer dual verification.

### Revenue model
- Per-property verification.
- Property-management SaaS add-on.

### Example
A rental platform requires agents to scan a QR at each viewing. Landlords receive a verified report of who attended and when.

**Additional examples:**
- A property platform requires the listing agent to verify presence at every scheduled viewing.
- A landlord receives a verification report including the tenant’s confirmed attendance at the inspection.
- A short-term rental host verifies that the cleaner arrived between guest check-out and check-in.
- A housing developer ranks sales agents by verified site-visit conversions.
